# YourWardrobe 3D avatar asset credits

The 3D human avatars and their idle animation clips are loaded from CodeLove 3D Models.

- Male avatar: https://models.codelove.in/models/male-adult-01/
- Female avatar: https://models.codelove.in/models/female-adult-01/
- Animation library: https://models.codelove.in/animations/
- License: MIT (the model provider states the license is embedded in each GLB; retain its copyright and permission notice when redistributing model files).

These are rigged, game-ready 3D characters, not photorealistic scans. The current V1.1 studio displays the base character models; it does not yet fit a user's uploaded shirt, pants, or footwear onto the avatar.

Model assets remain hosted by their provider and are loaded by the studio at runtime.
